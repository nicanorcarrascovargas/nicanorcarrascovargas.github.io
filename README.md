# Nicanor Carrasco-Vargas — personal website

Source for [nicanorcarrascovargas.github.io](https://nicanorcarrascovargas.github.io/).
The site has three pages: About, Research, and Talks.

## Editing

See [EDITING.md](EDITING.md) for the content files, bibliography format, local build
commands, and deployment instructions. Papers and talks are maintained in BibTeX;
page text is maintained in Markdown.

A commit to `master` runs the Jekyll build and local link check, then publishes to
GitHub Pages through [.github/workflows/deploy.yml](.github/workflows/deploy.yml).

## Scope

This repository keeps the layouts and shared assets used by the current site.
Unused al-folio blog, project-gallery, repository-card, and demo files have been
removed. The disabled CV page and its supporting files remain available.
